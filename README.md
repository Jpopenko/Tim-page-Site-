# Tim Page — War Photographer

Official archive and licensing site for the photography of Tim Page (1944–2022).

Built with Next.js 14, deployed via Vercel, backed by Wix CRM and Wix Media Manager.

## Dev

Requires Docker. No local Node.js needed.

```bash
docker compose up
```

Site runs at `http://localhost:3000`.

## Environment

Copy `.env.local.example` to `.env.local` and fill in credentials before starting.
